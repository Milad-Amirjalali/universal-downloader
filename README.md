# 🎵 YouTube Music High-Quality Extractor & Quality Inspector Bot

ربات هوشمند پایتون جهت استخراج آهنگ و فایل‌های صوتی از ویدیوها و موزیک‌های یوتیوب با بالاترین کیفیت ممکن (320kbps MP3)، به همراه ابزار تست و سنجش کیفیت فایل استخراج شده.

---

## ✨ ویژگی‌های برجسته
- 🎧 **استخراج با بالاترین کیفیت**: دانلود بهترین استریم صوتی یوتیوب و تبدیل آن با `FFmpeg` به MP3 320kbps بدون افت کیفیت.
- 📊 **آنالیز و سنجش کیفیت (Quality Inspection)**: بررسی بیت‌ریت (Bitrate)، نرخ نمونه‌برداری (Sample Rate)، کانال صوتی، حجم فایل و کدک.
- 🎨 **تزریق خودکار متادیتا و کاور (ID3 Tagging)**: افزودن عنوان آهنگ، نام خواننده/کانال و تصویر کاور ویدیو به فایل MP3.
- 🤖 **ربات تلگرام قدرتمند**: ارسال موزیک به شکل Telegram Audio جهت پخش مستقیم در موزیک پلیر تلگرام همراه با کپشن گزارش کیفیت.
- 💻 **حالت تست خط فرمان (CLI Mode)**: امکان تست و دانلود بدون نیاز به توکن تلگرام.

---

## 🛠 پیش‌نیازها
1. **Python 3.10 یا بالاتر**
2. **FFmpeg** (روی سیستم نصب باشد)

---

## 🚀 راهنمای نصب و اجرا

### ۱. نصب کتابخانه‌ها
یک محیط مجازی ساخته و پیش‌نیازها را نصب کنید:
```bash
python -m venv venv
# در ویندوز:
.\venv\Scripts\activate
# در لینوکس/مک:
source venv/bin/activate

pip install -r requirements.txt
```

---

### ۲. تست مستقیم در خط فرمان (CLI) - بدون نیاز به ربات تلگرام
می‌توانید یک لینک یوتیوب را مستقیماً تست کنید تا صدا با بالاترین کیفیت استخراج و گزارش کیفیت آن نمایش داده شود:

```bash
python main.py --cli "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
```

فایل استخراج شده در پوشه `downloads/` قرار می‌گیرد.

---

### ۳. راه‌اندازی ربات تلگرام
1. فایل `.env.example` را به `.env` تغییر نام دهید:
   ```bash
   cp .env.example .env
   ```
2. توکن ربات تلگرام خود را که از [@BotFather](https://t.me/BotFather) گرفته‌اید در فایل `.env` وارد کنید:
   ```env
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ```
3. ربات را اجرا کنید:
   ```bash
   python main.py
   ```

---

## 📂 ساختار پروژه
- `main.py`: نقطه ورود اصلی پروژه (پشتیبانی از CLI و Telegram Bot)
- `extractor.py`: موتور اصلی دانلود، تبدیل با FFmpeg، متادیتا و آنالیز کیفیت صوتی
- `bot.py`: کدهای هندلرها و ربات تلگرام
- `config.py`: تنظیمات متغیرهای محیطی و مسیرها
- `requirements.txt`: فهرست کتابخانه‌های مورد نیاز
